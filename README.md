# 🎨 ASCII Art Generator

画像をアスキーアートに変換するブラウザベースのツールです。

## 機能

- 📷 ドラッグ&ドロップで簡単画像アップロード
- 🎨 高精細なアスキーアート生成（70段階の詳細表現）
- 🔍 アップスケーリング対応（1x〜6x）
- 🌈 カラー対応
- 📋 クリップボードにコピー / ファイル保存

## 使い方

1. 画像をアップロード
2. 幅・高さ・キャラクターセットを調整
3. 「生成」ボタンで変換

## 技術

- Pure JavaScript（ライブラリ不要）
- Sobelエッジ検出 + 輝度ベースグラデーション
- Canvas APIによる画像処理
- バイキュービック補間で高品質アップスケール
